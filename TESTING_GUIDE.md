# Как запустить и протестировать «Ночную смену»

Инструкция для тех, кто не программирует. Команды нужно вводить в **терминал** (окно для текстовых
команд) — ниже написано, как его открыть. Каждую команду вводите целиком и нажимайте Enter.

---

## 1. Что установить (один раз)

| Программа | Зачем | Где взять |
| --- | --- | --- |
| **Node.js 22 LTS** (или 24) | запускает сборку и локальный сервер игры | [nodejs.org](https://nodejs.org/) → кнопка «LTS» → установить с настройками по умолчанию |
| **Браузер** | играть | Chrome, Яндекс Браузер, Edge или Firefox последней версии |
| Git *(необязательно)* | скачивать обновления проекта одной командой | [git-scm.com](https://git-scm.com/) |
| VS Code *(необязательно)* | удобно открыть папку и терминал в одном окне | [code.visualstudio.com](https://code.visualstudio.com/) |

Проверка: откройте терминал (см. раздел 3) и введите `node -v`. Должно появиться `v22.…` или `v24.…`
(подойдёт и `v20.19` или новее). Если пишет «не является внутренней или внешней командой» — Node.js
не установлен или терминал открыт до установки: закройте его и откройте снова.

## 2. Как получить проект

**Вариант А — без Git (проще):**
1. Откройте https://github.com/duanfuence/horror-shop
2. Слева сверху переключите ветку с `main` на **`claude/night-shift-prototype`**.
3. Зелёная кнопка **Code → Download ZIP**.
4. Распакуйте архив в простую папку, например `C:\games\horror-shop` (Windows) или `Документы/horror-shop` (macOS).

**Вариант Б — с Git:**
```
git clone -b claude/night-shift-prototype https://github.com/duanfuence/horror-shop.git
```
Обновить проект позже: в папке проекта `git pull`.

## 3. Как открыть терминал в папке проекта

- **Windows:** откройте папку проекта в Проводнике, щёлкните по адресной строке сверху, сотрите путь,
  введите `cmd` и нажмите Enter. Откроется чёрное окно уже в нужной папке.
- **macOS:** в Finder щёлкните по папке правой кнопкой → «Службы» → «Новый терминал по адресу папки».
  (Или откройте «Терминал», напечатайте `cd ` с пробелом и перетащите папку в окно, затем Enter.)
- **VS Code:** «Файл → Открыть папку…», затем «Терминал → Создать терминал».

Проверьте, что вы в правильной папке: команда `dir` (Windows) или `ls` (macOS) должна показать файл `package.json`.

## 4. Первый запуск на компьютере

```
npm install
npm run dev
```

1. `npm install` скачивает нужные библиотеки (≈ 1 минута, только в первый раз и после обновлений проекта).
2. `npm run dev` запускает игру. В терминале появится строка `Local: http://localhost:5173/`.
3. Откройте в браузере **http://localhost:5173** — появится главное меню.
4. Остановить игру: в терминале нажмите **Ctrl+C** (на Windows может спросить «Завершить выполнение? (Y/N)» — нажмите `Y`).

В следующие разы достаточно `npm run dev`.

> **Windows, PowerShell:** если появляется ошибка «выполнение сценариев отключено» (`npm.ps1 cannot be loaded`),
> откройте терминал через `cmd` (как в разделе 3) — там этой ошибки нет.

### Проверить «как у игроков» (собранная версия)

```
npm run build
npm run preview
```
Откройте **http://localhost:4173**. Эта версия ближе к той, что будет на Яндекс Играх.

## 5. Тест на телефоне (в домашней Wi-Fi сети)

Телефон и компьютер должны быть подключены **к одной и той же домашней Wi-Fi сети**.

```
npm run build
npm run preview:lan
```

1. В терминале появится строка вида `Network: http://192.168.1.34:4173/` — это адрес вашего компьютера в сети.
2. Наберите **этот адрес целиком** в браузере телефона (цифры у вас будут свои).
3. **Windows** может спросить разрешение для Node.js в брандмауэре — разрешите только для **частных сетей**.
4. После теста остановите сервер: **Ctrl+C** в терминале.

Если не открывается:
- проверьте, что телефон не в мобильном интернете и не в гостевой Wi-Fi (гостевые сети часто изолируют устройства);
- отключите VPN на телефоне и компьютере;
- проверьте, что окно терминала с `preview:lan` открыто и не показывает ошибку;
- открывайте именно по IP-адресу: адрес вида `имя-компьютера.local` сервер намеренно не пускает (защита).

**Безопасность:** `preview:lan` делает игру видимой всем устройствам в этой сети. Используйте только дома или
в доверенной сети, не в кафе и не на вокзале. Обычные `npm run dev` и `npm run preview` видны только на этом компьютере.

На телефоне: сначала коснитесь экрана — браузеры включают звук только после касания; на iPhone проверьте,
что не включён беззвучный режим. Играть удобнее в горизонтальном положении, но портретное тоже поддерживается.

## 6. Как начать прохождение заново

- **Во время смены:** пауза (Esc или кнопка ❚❚) → «Выйти в меню» → «Новая смена». Текущее сохранение заменится.
- **После концовки:** кнопка «Начать смену заново».
- **Продолжить с места остановки:** в меню «Продолжить смену» (игра сохраняется сама каждые 5 игровых минут
  и после каждого разговора; последний час смены, после 05:00, не сохраняется — при перезагрузке вернётесь к ~04:55).
- **Полный сброс** (стереть и открытые концовки, и настройки) — очистить данные сайта в браузере:
  - Chrome / Яндекс Браузер на компьютере: на странице игры **F12 → вкладка «Application» («Приложение») →
    «Storage» → «Clear site data»**; или нажмите значок слева от адреса → «Настройки сайтов» → «Удалить данные».
  - Телефон: настройки браузера → «Настройки сайтов» → найти адрес игры → «Очистить данные».
    Ещё проще — открывать игру во **вкладке инкогнито**: каждый раз всё с нуля.
- Сохранения привязаны к адресу: у `localhost:5173`, `localhost:4173` и адреса для телефона они **разные**.

### Ускоренная проверка (для себя)

Откройте **http://localhost:5173/?debug=1&speed=10** — игра пойдёт в 10 раз быстрее (максимум ×15).
Ускоряется всё: часы, печать текста, таймеры на выбор и терпение покупателей — это режим для быстрой проверки
сюжета, а не для оценки ощущений. Работает только на вашем компьютере и в домашней сети, у игроков на платформе — нет.

## 7. Где смотреть ошибки

**В терминале** — если команда `npm …` не выполнилась, причина написана красным или словами `ERR!`/`error`.
Частые случаи:
- `node` или `npm` «не является командой» → Node.js не установлен; переустановите и откройте терминал заново;
- `Port 5173 is in use` → игра уже запущена в другом окне терминала: закройте его или откройте адрес,
  который предложит Vite (например, `5174`);
- ошибка при `npm install` → проверьте интернет и повторите команду.

**В браузере на компьютере** — консоль разработчика:
- Windows: **F12** (или Ctrl+Shift+I) → вкладка **Console** («Консоль»);
- macOS: **Cmd+Option+I** → **Console**.
Красные строки — ошибки. Сделайте скриншот или скопируйте текст и пришлите мне.

**На телефоне** проще всего прислать скриншот и описание. Для подробностей:
- Android + Chrome: подключить телефон по USB, включить «Отладку по USB», на компьютере открыть `chrome://inspect`;
- iPhone: «Настройки → Safari → Дополнения → Веб-инспектор», затем на Mac в Safari меню «Разработка».

**Что написать в отчёте об ошибке:** что вы делали; что ожидали; что произошло; время на игровых часах;
устройство и браузер; скриншот; текст из консоли, если есть.

## 8. На что смотреть при тестировании

- Понятно ли без подсказок, что делать в первые 2 минуты?
- Где было страшно, где скучно, где непонятно?
- Читается ли текст, удобно ли нажимать кнопки (особенно на телефоне)?
- Нормальная ли громкость, не раздражают ли звуки?
- Сколько длилась смена (на экране итогов) и какая концовка выпала? Запишите и **код ночи** с экрана итогов —
  по нему можно воспроизвести ту же ночь (фоновые события у каждого прохождения свои).
- Не слишком ли часто или редко что-то происходит «само по себе» (лампы, стуки, тени, звуки)?
- **Камеры.** Иногда на камерах что-то меняется: лишний предмет, сдвинутый стул, тень, фигура, неправильное
  время. Если заметили — нажмите «✎ Зафиксировать» и выберите, что не так. Расскажите: замечали ли вы
  изменения сами, понятно ли, что выбирать, не раздражает ли «журнал занят» после ошибки, не приходилось ли
  сидеть в камерах вместо работы. Записи видны в журнале на вкладке «Камеры».
- **Запись камер.** Кнопка «⏪ Запись» на экране камер показывает последний час. Время в магазине при этом
  идёт. Попробуйте найти на записи то, чего не было в эфире, и сравнить две минуты или две камеры.
  Расскажите: удобно ли перематывать пальцем, понятно ли, где вы — в записи или в эфире, хватает ли часа.
- Были ли зависания, пропавшие кнопки, ошибки?

## 9. Архив для Яндекс Игр (на будущее)

```
npm run build
npm run zip
```
Архив появится в папке `release/` (например, `release/night-shift-0.1.0.zip`). **Пока не загружайте его на платформу:**
требования Яндекс Игр к SDK и рекламе ещё нужно сверить с актуальной документацией.
