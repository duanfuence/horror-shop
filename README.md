# Ночная смена

Психологический хоррор-симулятор ночного продавца для браузера (цель — Яндекс Игры).
Ночь с 14 на 15 ноября, круглосуточный магазин «Колосок» на окраине вымышленного Тихоборска.
Обычная работа за кассой, камеры наблюдения, рабочий журнал, телефон с двумя линиями — и правила,
которые с каждым часом всё меньше похожи на обычные.

- Одна законченная смена (≈ 12–15 минут), 6 концовок, включая тайную.
- События реагируют на поведение игрока: скрытые параметры, отложенные последствия, улики.
- Вся графика и весь звук генерируются кодом — сторонних ассетов нет.
- Управление мышью, клавиатурой и касанием; телефон в альбомной и портретной ориентации.

## Быстрый старт

Нужен [Node.js](https://nodejs.org/) 20 или новее (проверено на 22).

```bash
npm install        # установить зависимости (один раз)
npm run dev        # запустить игру локально → http://localhost:5173
```

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Локальный сервер с автообновлением |
| `npm run build` | Проверка типов и сборка в `dist/` |
| `npm run preview` | Посмотреть собранную версию → http://localhost:4173 |
| `npm test` | Автотесты: ядро, сюжет (симуляция всех веток), темп смены |
| `npm run zip` | Архив `release/night-shift-<версия>.zip` для загрузки на Яндекс Игры |

### Проверка в браузере (Chromium через Playwright)

При запущенном `npm run dev`:

```bash
node scripts/e2e.mjs http://localhost:5173/          # сценарий на 3 экранах: ПК, телефон альбомно/портретно
node scripts/playthrough.mjs http://localhost:5173/  # бот проходит смену целиком тремя стратегиями
node scripts/boot-stress.mjs http://localhost:5173/  # 20 холодных запусков подряд
node scripts/showcase.mjs http://localhost:5173/     # скриншоты ключевых визуальных моментов
```

Надёжнее запускать их на собранной версии (`npm run build && npm run preview`, адрес http://localhost:4173/):
dev-сервер перезагружает страницу при правке кода и прерывает тест. Скриншоты сохраняются в `e2e-output/`.
Страница `art-preview.html` (только в dev-режиме) показывает процедурную графику отдельно от игры.

### Режим отладки

`http://localhost:5173/?debug=1&speed=10` — время идёт в 10 раз быстрее, в консоли доступен объект
`__ns` (`__ns.session.state` — состояние мира, `__ns.session.skipMinutes(30)` — перемотка).

## Управление

- Клик/касание по предметам: холодильник (термометр), монитор (камеры), телефон, журнал, служебная дверь,
  фото и календарь на стене, витрина; по покупателю — рассмотреть его.
- **Пробел / Enter** — дальше, **1–9** — выбор варианта.
- **C** — камеры (в режиме камер **1–4** или **←/→**), **J** — журнал, **P** — телефон, **T** — термометр.
- На кассе: **Пробел** — пробить следующий товар, **Enter** — продать.
- **Esc** — пауза / закрыть окно.

## Структура проекта

```
src/
  core/        Ядро без зависимостей от графики: состояние мира, часы, исполнение сцен,
               триггеры, задачи, сохранения, язык описания сцен (dsl.ts)
  content/     Сюжет: shift1/ — первая смена (персонажи, памятка, сцены, хронология, концовки)
  game/        Phaser: процедурная пиксельная графика (art/), сцены магазина и камер (scenes/)
  ui/          Интерфейс на HTML/CSS: меню, HUD, диалоги, касса, журнал, телефон, камеры, итоги
  audio/       Процедурный звук на Web Audio API
  platform/    Платформа: локальный браузер или Яндекс Игры (SDK подключается автоматически)
tests/         Vitest: ядро, симуляция прохождений, темп
scripts/       e2e в браузере, полное прохождение ботом, упаковка в ZIP
docs/          Дизайн-документ (GDD.md) и руководство по сюжетному контенту (CONTENT.md)
```

Сюжет описан данными (`src/content/shift1/scenes.ts`): новую сцену или смену можно добавить,
не трогая ядро. Подробно — в [docs/CONTENT.md](docs/CONTENT.md).

## Яндекс Игры

Интеграция подготовлена в `src/platform/`:

- SDK загружается с адреса `/sdk.js` автоматически, когда игра открыта не на localhost
  (`?sdk=0` — отключить, `?sdk=1` — включить принудительно, например при локальной проверке).
- `LoadingAPI.ready()` вызывается, когда главное меню готово.
- `GameplayAPI.start()/stop()` — при начале смены и выходе в меню/на экран итогов.
- Пауза и отключение звука при сворачивании вкладки и по событиям `game_api_pause` / `game_api_resume`.
- Сохранения: облачные данные игрока (`player.setData`, не чаще раза в 5 с) с локальной копией.
- Межстраничная реклама — только после экрана итогов, при переходе к новой смене или в меню.
  Во время смены реклама не показывается никогда. Реклама за вознаграждение подготовлена в API,
  но в первой версии не используется.

Локальная проверка с настоящим SDK — официальным инструментом Яндекса:

```bash
npm run build
npx @yandex-games/sdk-dev-proxy -p dist --dev-mode
# открыть адрес, который покажет прокси, с параметром ?sdk=1
```

Публикация: `npm run build && npm run zip`, затем загрузить `release/*.zip` в консоли разработчика.
Названия методов SDK сверены с официальным пакетом `@yandex-games/sdk-dev-proxy` и типами `@types/ysdk`;
актуальные требования модерации нужно перепроверить в
[документации](https://yandex.ru/dev/games/doc/ru/) перед отправкой (см. чек-лист в docs/GDD.md).
